🎓 DemoPrep Academy – AI Enquiry Assistant DEMO

Answers student and parent questions only from the institute's own documents, and shows which document each answer came from. If the answer isn't in the documents, it says so instead of guessing.

📄 View the source documents the bot uses (SAMPLE DATA)
How it works: the documents are split into sections, indexed with BM25 keyword retrieval in your browser, and the best-matching passages are returned with numbered citations. No data leaves this page. For a real business, the same setup runs on their brochure, fee sheet, FAQs or website, on the website or on WhatsApp, and can use an LLM to write the answers in a more natural way.
